Frequently Asked Questions

Common questions about image dimensions.

Image dimensions describe the width and height of an image, normally measured in pixels. For example, 1920 × 1080 means 1920 pixels wide and 1080 pixels high.

Aspect ratio is the relationship between an image's width and height. Common ratios include 16:9, 4:3 and 1:1.

The image information is read locally by JavaScript in your browser. This page does not need to upload the image to a ToolifyHub server.

Megapixels represent the approximate number of pixels in an image. It is calculated from the image width multiplied by its height and divided by one million.
